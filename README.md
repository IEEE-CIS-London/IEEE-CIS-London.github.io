# IEEE CIS London Section — Official Website

Official website for the **IEEE Computational Intelligence Society (CIS) — London Section Chapter** (`IEEE_London_CIS_section`).

🌐 **Live Website URL**: [https://sankunliu.github.io/IEEE_London_CIS_section/](https://sankunliu.github.io/IEEE_London_CIS_section/)

## Features
- **Academic & IEEE Visual Identity**: Designed in alignment with IEEE Global & IEEE Computational Intelligence Society standards, featuring an interactive neural-network canvas hero.
- **Chapter Events & Symposia (`#events`)**: Filterable upcoming and past events with venue details, speaker highlights, agenda reader modal, and registration links.
- **Research Topics & Pillars (`#topics`)**: Covers Neural Networks, Evolutionary Computation, Fuzzy Systems & Explainable AI (XAI), and Emerging Agentic AI topics.
- **Event Photo Gallery (`#gallery`)**: Categorized photo wall with full-screen Lightbox preview and keyboard navigation.
- **Executive Committee & Join Us (`#committee`, `#contact`)**: Showcases chapter leadership and membership onboarding.
- **Built-in Administrator Portal & Serverless Cloud Sync**:
  - Click **Admin Login** in the top navigation bar.
  - Manage Events, upload local photos (automatically resized & compressed via HTML5 Canvas), publish Research Topics, and update Committee members.
  - Supports **One-Click Live Publishing to GitHub Pages** via the GitHub Contents API (`data/site-data.json` and `uploads/`).
